# Редактор базы RimWorld (для Claude)

Правится только `layout.py` (стены, комнаты, мебель, зоны) — всё остальное считает пайплайн.

    cd tools
    python3 render.py      # проверка пересечений + картинка plan.png
    python3 check.py       # достижимость комнат, заблокированные двери
    python3 apply_world.py # собирает ../mirella fans_edited.rws из ../mirella fans.rws
    python3 validate.py    # XML, здоровье новых построек, дубли, битые ссылки

Что делает пайплайн: сносит старые постройки, переносит верстаки/койки/бочки, ставит стены/двери/мебель
с правильным здоровьем, прокладывает провода и подключает потребителей, меняет полы/крыши/зоны/области,
расставляет работы/расписание/политики колонистов. Нужен Pillow (`pip install pillow`).
Не проверено в самой игре — только по файлу.
